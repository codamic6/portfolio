# **App Name**: Luqman Portfolio

## Core Features:

- Animated Hero Section: Dynamic Hero Section with Animated Background: Engaging introduction with Luqman's title, description, and animated gradient/particle background to capture immediate attention.
- Portfolio Showcase: Interactive Portfolio Showcase: Grid-based gallery that opens project details in a modal/lightbox, displaying client info, tools used (Figma, Adobe XD, Photoshop), and descriptions.
- Skills Section: Skills Visualization: Animated progress bars or icon-based skills representation showing proficiency in Figma, XD, Photoshop, Illustrator, Webflow, and UI/UX principles.
- Testimonials Slider: Testimonials Carousel: Display client feedback via a carousel slider to build trust and credibility.
- Contact Form: Contact Form: A simple styled form with name, email, and message fields.
- Social Links: Link to external sites (Fiverr, Behance, Dribbble, LinkedIn).
- Sticky Footer: Sticky Footer: Consistently visible footer featuring Luqman's signature.

## Style Guidelines:

- Primary color: Soft Lavender (#E6E6FA) to give a modern and calming feel.
- Background color: Off-White (#F8F8FF) for a clean and minimal aesthetic.
- Accent color: Pale Turquoise (#AFEEEE) to highlight interactive elements and create visual interest.
- Headline font: 'Poppins', sans-serif, for a clean, contemporary look.
- Body font: 'PT Sans', sans-serif, providing readability and a modern feel.
- Use minimalist line icons to represent skills and categories, maintaining a clean design.
- Employ rounded cards, glassmorphism effects, and soft drop-shadows to enhance the futuristic and modern design.
- Implement smooth Framer Motion or GSAP animations for transitions and interactive elements to give a professional, dynamic user experience.
